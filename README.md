# mikeleg.github.io

Sito personale statico di Mike Leg, realizzato con [Astro](https://astro.build/) e pubblicato su GitHub Pages.

## Caratteristiche
- Blog con articoli in Markdown
- Stile minimal e accenti fluo
- SEO-friendly (meta tag, sitemap, robots.txt)
- Deploy automatico con GitHub Actions
- Ottimizzato per la condivisione social

## Struttura
- `src/pages/` — pagine principali
- `src/content/posts/` — articoli in Markdown
- `src/layouts/` — layout riutilizzabili
- `src/components/` — componenti UI
- `src/styles/` — stili globali
- `public/` — asset statici (favicon, robots.txt, immagini)

## Avvio locale
```bash
npm install
npm run dev
```

## Deploy
Il deploy avviene automaticamente su ogni push su `main` tramite GitHub Actions.
